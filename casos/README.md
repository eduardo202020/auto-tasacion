# Material de referencia para la validación

Este directorio conserva los insumos usados para reproducir y revisar el flujo
de Auto Tasaciones en el entorno de desarrollo.

| Ubicación | Uso |
| --- | --- |
| `10-casos/D01.pdf` a `10-casos/D10.pdf` | Lote de diez documentos usado en las validaciones Cloud, Excel, PAD y consulta segura de 3270. |
| `excel-procesado-listo-para-pasar-macro-10-casos.xlsm` | Libro preparado para contrastar el mapeo de los diez casos con la plantilla MASIVO. |

Los otros materiales de referencia del mismo ejercicio se mantienen en la raíz
del repositorio:

| Archivo | Uso |
| --- | --- |
| `excel-procesado-listo-para-pasar-macro.xlsm` | Libro de referencia de la macro. |
| `macro-tasaciones-richard.xlsm` | Macro heredada que sirve de comparación funcional. |
| `reglas-de-negocio-ajustadas-operador.xlsx` | Reglas revisadas por Operaciones. |
| `login.png` | Pantalla de referencia para iniciar la sesión PCOMM en BPO. |

La trazabilidad de la ejecución está en
[`../docs/operacion/ejecucion-macro-3270-pad-2026-10-14.md`](../docs/operacion/ejecucion-macro-3270-pad-2026-10-14.md).
