# Skills locales de `auto-tasacion`

Estas skills documentan decisiones que un agente general no puede deducir solo
del código. Están versionadas junto al proyecto para que las futuras sesiones
trabajen con el mismo contrato y límites de seguridad.

| Skill | Cuándo leerla |
|---|---|
| [`tasaciones-cloud-run`](tasaciones-cloud-run/SKILL.md) | Cambios en la función, PDF, IA, catálogos, pruebas o despliegue. |
| [`tasaciones-contrato-excel`](tasaciones-contrato-excel/SKILL.md) | Cambios en hojas/tablas Excel, Power Automate, PAD o trazabilidad. |

`AGENTS.md` enlaza estas skills como instrucciones locales. Cuando el cliente
de IA permita registrar skills por carpeta, puede apuntar directamente a este
directorio; no hace falta copiar credenciales ni referencias locales para
usarlas.
